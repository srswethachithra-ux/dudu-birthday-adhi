DuDuVerse multipage birthday website

Open index.html with VS Code Live Server.
Pages: Home, Gym Champion, Games, Open Your Gift, Love Letter, Final Surprise.
Photos selected on Gift page are local previews only. For a public website, put shareable image files in this folder and add their paths to gift.html.
To publish with GitHub Pages, upload all files in this folder (not just the ZIP) to the repository root.


REAL PHOTO VERSION:
The five supplied photos are included in the photos/ folder and displayed on gift.html.
When publishing, upload the entire contents of DuDuVerse_MultiPage including the photos folder.
If using GitHub Pages, keep photos/ alongside index.html and the other HTML files.
